# QR Code Generator

Made from the Tool Factory starter. Follow the pipeline in `web-tool-framework.md`.

- `site.mjs`: pages, copy, SEO titles and the tool's HTML. Search for `TODO`.
- `src/tool.js`: the tool's browser code.
- `tool.css`: styles only this tool needs.

Build: `npm run preview -- qr-code` (private preview) or `npm run build -- qr-code` (production). Output: `tools/qr-code/dist`.
