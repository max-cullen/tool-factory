# Username Generator

Made from the Tool Factory starter. Follow the pipeline in `web-tool-framework.md`.

- `site.mjs`: pages, copy, SEO titles and the tool's HTML. Search for `TODO`.
- `src/tool.js`: the tool's browser code.
- `tool.css`: styles only this tool needs.

Build: `npm run preview -- name-generator` (private preview) or `npm run build -- name-generator` (production). Output: `tools/name-generator/dist`.

## Dependencies

None. Plus Jakarta Sans (SIL OFL 1.1) comes from the shared framework.
